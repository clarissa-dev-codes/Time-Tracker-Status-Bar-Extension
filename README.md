# Ducky Time Tracker & Focus Companion 🦆💻

Ducky is an interactive, state-aware productivity extension for VS Code. It features a reactive mascot ("Ducky") that tracks your coding sessions, helps you manage your focus, dynamically breaks down your language metrics, and protects your health by reminding you to take breaks.

## 🚀 Key Features

*   ⏱️ **Smart Session Tracking**: Automatically monitors active coding hours.
*   💤 **Intelligent Idle Detection**: Pauses tracking automatically when you step away from your desk.
*   📊 **Language Breakdown Metrics**: Generates a dynamic layout breakdown of your programming languages used during a session.
*   🍅 **Integrated Pomodoro Timer**: Switches into a dedicated 25-minute sprint directly inside the primary panel interface.
*   🎨 **Customizable Mascot Palette**: Includes a responsive color tint selection slider to personalize your Ducky companion.
*   🔥 **Interactive Break Reminders**: Alerts you after continuous long coding stretches. Ducky transitions to an urgent "angry" state if break alerts are ignored.
*   💾 **Persistent Local Caching**: Saves active session progress securely on your hard drive across VS Code restarts.
*   📈 **Full-Tab Analytics Dashboard**: Expands into a detailed, wide-grid workspace report column at the click of a link.

## 📦 Installation & Setup

1. Open your extension's workspace sidebar panel.
2. The tracker begins monitoring immediately upon launch.
3. Use the sidebar controls to adjust your daily hours goal or to toggle Pomodoro focus intervals.

## 🔧 Technologies Used

*   **TypeScript / Node.js**: Backend state management architecture.
*   **VS Code Extension API**: Webview View Provider framework and global storage states.
*   **HTML5 / CSS3 / JavaScript**: Responsive sidebar presentation layouts and animation rendering.
